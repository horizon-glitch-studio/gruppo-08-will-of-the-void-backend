# Will of the Void – Backend

Backend of **Will of the Void**, a digital collectible card game developed for the Laboratorio Integrato (group 08).

Stack: Java 25, Spring Boot 4.1.2, PostgreSQL. The source code will be added in the next phases.

## Documentation

- [Tech stack](docs/tech-stack.md): technologies and dependencies, with the reasons behind each choice.
- [Database schema](docs/database/database-schema.md): the 24 tables in 7 views, with Mermaid diagrams and relationships.
- [DBML schema](docs/database/will-of-the-void.dbml): paste it into [dbdiagram.io](https://dbdiagram.io) to view or edit the schema.
- [SQL schema](docs/database/schema.sql): PostgreSQL script kept in sync with the DBML, also the first Flyway migration.
